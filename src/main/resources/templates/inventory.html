Receive stock

Posting immediately creates stock. Use one receipt for up to 50 product lines. For variable-weight packages, enter their actual total measured quantity in the product's base unit. Leave it blank only when using a defined fixed packaging conversion. Enter purchase cost per delivered unit, not per base unit unless those units are the same. Batch totals are calculated on posting, rounded half up to the currency's standard decimal places.

Reverse a movement

Select Reverse in the movement history. This posts an opposite movement; it cannot remove stock already consumed. A receipt line is reversed individually.

Low-stock minimum

Minimums are per branch/product in its base unit. Use Set minimum above to edit an existing value. Zero is a valid minimum; stock at or below it triggers an alert.
